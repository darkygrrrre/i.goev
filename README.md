# Лендинг-визитка Игоря Гоева

Одностраничный сайт — «прокачанное резюме».

## Файлы
- `index.html` — сама страница (откройте двойным кликом, чтобы посмотреть)
- `photo-1.jpg` — фото
- `resume.pdf` — резюме для кнопки «Скачать»

## Как посмотреть локально
Дважды кликните `index.html` — откроется в браузере.

## Как опубликовать бесплатно (GitHub Pages)

1. Зарегистрируйтесь на [github.com](https://github.com) (если нет аккаунта).
2. Нажмите **+** → **New repository**. Название: `goev` (или любое). Поставьте **Public**. Создайте репозиторий.
3. На странице репозитория нажмите **uploading an existing file** (или `Add file` → `Upload files`) и перетащите туда все три файла: `index.html`, `photo-1.jpg`, `resume.pdf`. Нажмите **Commit changes**.
4. Откройте **Settings** → **Pages** (слева). В блоке **Branch** выберите ветку `main` и папку `/ (root)`, нажмите **Save**.
5. Через 1–2 минуты появится ссылка вида `https://ваш-логин.github.io/goev/` — это и есть ваш сайт.

Чтобы ссылка была короче (`https://ваш-логин.github.io/`), назовите репозиторий `ваш-логин.github.io`.

## Как поменять фото
Положите новый файл с именем `photo-1.jpg` вместо старого — страница обновится автоматически.

## Как поменять резюме для скачивания
Замените `resume.pdf` своим файлом с тем же именем.
