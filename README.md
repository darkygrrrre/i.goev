# Лендинг-визитка Игоря Гоева

Одностраничный сайт — «прокачанное резюме».

## Файлы
- `index.html` — сама страница (откройте двойным кликом, чтобы посмотреть)
- `photo-1.jpg` — фото
- `resume.pdf` — резюме для кнопки «Скачать»

## Как поменять фото
Положите новый файл с именем `photo-1.jpg` вместо старого — страница обновится автоматически.

## Как поменять резюме для скачивания
Замените `resume.pdf` своим файлом с тем же именем.
